# FIT3179 Data Visualisation 1

## Australia's Streaming Revolution

An interactive Tableau visualisation exploring changes in Australian television and streaming behaviour using data from ACMA and ABS.

### Project Highlights
- analysed streaming and traditional television trends
- created calculated measures and derived comparisons
- used multiple chart types for time-series, ranking, and category comparisons
- applied visual hierarchy, annotations, colour, and storytelling principles
